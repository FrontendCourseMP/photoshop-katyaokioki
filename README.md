# Графический редактор (photoshop-katyaokioki)

Проект для курса "Технологии компьютерной графики" — лабораторные работы по обработке изображений.

Хостинг (GitHub Pages): PLACEHOLDER — добавить ссылку после первого деплоя

Запуск локально:

1. Установить зависимости: `npm ci`
2. Запустить dev-сервер: `npm run dev`

Структура:
- src/core — логика обработки изображений
- src/store — состояние
- src/components — UI
- src/tools — инструменты (пипетка, уровни и т.д.)
