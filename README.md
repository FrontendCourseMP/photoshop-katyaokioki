# Графический редактор (photoshop-katyaokioki)

Проект для курса "Технологии компьютерной графики" — лабораторные работы по обработке изображений.

Хостинг GitHub Pages: https://frontendcoursempl.github.io/photoshop-katyaokioki/

Лабораторная 1: цифровое представление изображения.
- загрузка PNG, JPG, GB7
- собственный GB7 decoder/encoder
- сохранение в PNG, JPG, GB7
- отображение на canvas с адаптацией под окно браузера
- статус бар с размерами и глубиной цвета

Лабораторная 2: цветовые каналы и пипетка.
- панель каналов с миниатюрами и переключением
- применение выбранных каналов к главному canvas
- пипетка с RGB и CIELAB (L*, a*, b*)

Лабораторная 3: уровни и гистограмма.
- диалоговое окно "Уровни"
- гистограмма в линейном и логарифмическом режимах
- контроль по master / R / G / B / A
- LUT-обработка, предпросмотр и apply/cancel/reset

Локальный запуск:
1. `npm ci`
2. `npm run dev`

Сборка:
- `npm run build`

Структура проекта:
- `src/core` — чистая логика (GB7, преобразования изображений, LUT, уровни)
- `src/store` — состояние приложения (Zustand)
- `src/components` — UI-компоненты интерфейса
- `src/tools` — инструменты редактора

Замечание по формату GB7:
- сигнатура: `47 42 37 1D`
- версия: 1 байт
- флаг: 1 байт
- ширина и высота: 2 байта big-endian
- один байт на пиксель с 7-битной яркостью и битом маски в старшем бите
