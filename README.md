# Графический редактор (photoshop-katyaokioki)

Проект для курса «Технологии компьютерной графики»: лабораторные работы по обработке изображений.

Хостинг: https://photoshop-katyaokioki.onrender.com/

Стек: React + TypeScript + Vite, состояние в Zustand. Вся работа с пикселями (декодер и кодер GB7, каналы, гистограмма, LUT, интерполяция, свёртка) написана вручную, без библиотек.

## Архитектура

Внутри редактора изображение хранится как `RasterImage` (`src/core/raster.ts`):

| поле | смысл |
|---|---|
| `channels` | 1: Gray, 2: Gray+Alpha, 3: RGB, 4: RGBA |
| `bits` | разрядность цветовых каналов: 8 для PNG/JPG, **7 для GB7** (значения 0…127) |
| `data` | пиксели построчно, каналы чередуются, длина `W × H × channels` |

Поэтому все инструменты работают с реальным числом каналов и реальным диапазоном значений. Например, у GB7 с маской два канала (серый и альфа), уровни строятся по шкале 0…127, а фильтр предлагает каналы «Серый» и «Альфа».

Масштаб отображения хранится отдельно от изображения (`ViewState` в `Workspace.tsx`) и пиксели не меняет. Холст всегда занимает всю рабочую область, видимая часть изображения перерисовывается собственной интерполяцией (`renderViewport`).

```
src/core/raster.ts          модель изображения, сборка каналов для показа, миниатюры, пипетка
src/core/formats/gb7.ts     декодер/кодер GrayBit-7
src/core/formats/headers.ts чтение глубины цвета из заголовков PNG (IHDR) и JPEG (SOFn)
src/core/formats/index.ts   загрузка (формат по сигнатуре) и сохранение PNG/JPG/GB7
src/core/interpolation.ts   ближайший сосед, билинейная; resizeRaster, renderViewport
src/core/levels.ts          гистограмма, LUT, гамма, применение уровней
src/core/convolution.ts     ядра, расширение краёв, свёртка 3×3
src/core/convolution.worker.ts, filterRunner.ts — свёртка в Web Worker с отменой
src/components/             Modal (общий <dialog>), Workspace, StatusBar, ChannelPanel,
                            InfoPanel, LevelsDialog, FilterDialog, ResizeDialog, MenuBar
```

## Лабораторная 1: цифровое представление изображения
- Открытие PNG, JPG и GB7 через меню, Ctrl+O или перетаскиванием. Формат определяется по сигнатуре файла.
- Собственный декодер и кодер GB7: заголовок big-endian, 7 бит серого, бит 7 — маска.
- Сохранение в PNG, JPG (прозрачность заменяется белым фоном) и GB7.
- Пропорции сохраняются: изображение рисуется с одинаковым масштабом по X и Y.
- В строке состояния: имя и формат файла, ширина × высота, **глубина цвета в битах на пиксель** из заголовка файла:
  - GB7 без маски — 7 бит, с маской — 8 бит (7 + 1);
  - PNG: Gray 8, Gray+Alpha 16, RGB 24, RGBA 32, 16-битные PNG — 48/64, палитровые — по bit depth;
  - JPEG: 8 (grayscale) или 24 бита.
- Строка состояния прижата к низу окна, элементы масштаба не двигаются. Каждая величина выводится один раз.
- Раскладка подстраивается под ширину окна: на узком экране панели уходят под холст.

## Лабораторная 2: каналы и пипетка
- Панель каналов показывает столько миниатюр, сколько каналов у изображения (1/2/3/4). Миниатюры в градациях серого, с сохранением пропорций.
- Клик включает или выключает канал. Если оставить только альфу, показывается маска. Исходный массив не меняется.
- Пипетка (клавиша I): координаты X/Y в пикселях изображения с учётом масштаба и сдвига, RGB 0…255, CIELAB. Для GB7 дополнительно показывается исходное 7-битное значение.

## Лабораторная 3: уровни
- Диалог `<dialog>`. Каналы: Master и R/G/B для цветных изображений, Master для серых, плюс Alpha, если она есть.
- Гистограмма 0…127 для GB7 и 0…255 для 8-битных. Для Master считается светлота по Rec. 601. Переключатель линейной и логарифмической шкалы.
- Три маркера под осью гистограммы: чёрная точка, полутона и белая точка. Маркеры не заходят друг за друга. Полутона задают гамму от 0.1 до 9.9: сдвиг влево осветляет, вправо затемняет.
- Настройки каждого канала сохраняются при переключении. Сначала применяется LUT канала, затем Master; альфу Master не затрагивает.
- Предпросмотр (включён по умолчанию, перерисовка через requestAnimationFrame). «Сбросить» возвращает значения, не закрывая окно; «Отмена» закрывает без изменений; «Применить» применяет.

## Лабораторная 4: масштабирование
- Собственные методы «ближайший сосед» и «билинейная» с общим интерфейсом `Interpolator`. Новый метод добавляется одним объектом в `INTERPOLATORS`.
- В строке состояния: ползунок 12–300 %, поле ввода, готовые значения и «Вписать в окно». Также масштаб меняется колесом с Ctrl относительно курсора, клавишами + / − / 0 и через меню «Вид».
- При открытии изображение вписывается в окно с отступом не меньше 50 px, масштаб ограничен 12–300 %.
- Изображение перерисовывается в центре холста. При увеличении считается только видимая часть, поэтому большие изображения на 300 % не съедают память. Перемещение вида — инструмент «Рука» или колесо мыши.
- Диалог «Размер изображения»: мегапиксели до и после, проценты или пиксели, связь пропорций, выбор алгоритма с подсказкой, валидация (целые 1…10000 px, проценты до 1000 %).

## Лабораторная 5: фильтрация
- Диалог: предустановки (тождественное, резкость, Гаусс 3×3, прямоугольное размытие, Прюитт X/Y), сетка 3×3, нормировка (делитель — сумма ядра или 1, если сумма 0), выбор каналов по реальным каналам изображения, стратегия краёв (чёрный, белый, копирование), предпросмотр, кнопки «Сбросить», «Закрыть», «Применить».
- Перед свёрткой каждый канал явно расширяется на 1 px по выбранной стратегии, поэтому размер изображения не меняется (`padChannel`).
- Свёртка выполняется в Web Worker с индикатором прогресса. Интерфейс остаётся отзывчивым, новый запуск отменяет предыдущий.
